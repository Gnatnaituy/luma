# Luma

Luma 是一个完全使用 macOS 原生技术实现的轻量工具启动器：Swift、SwiftUI、AppKit 和 Carbon，全工程不包含 Electron、Chromium、WebView 或 JavaScript 运行时。

## 已实现

- 默认使用 `⌥ Space` 全局唤起/隐藏浮动面板，不需要辅助功能权限；可在配置页录入任意带 `⌘`、`⌥` 或 `⌃` 的组合键
- 唤起时仅显示搜索框，输入后展开匹配结果；选中工具后只显示该工具内容，不常驻工具侧边栏
- 搜索框右侧提供原生二级配置页入口，快捷键修改后立即注册并持久化
- 支持添加多组“快捷键 → 关键词”绑定；唯一命中插件时直接进入工具，多结果时展示匹配列表供选择
- 紧凑搜索栏采用更薄的 58 点高度与更明亮的系统文本背景色
- 默认启动位置采用用户选定的屏幕锚点；窗口拖动位置与用户调整的面板高度在本次运行期间保留，重启后恢复该默认位置和默认高度
- 原生浮动面板隐藏关闭、最小化和缩放三个标题栏控制按钮
- 工具页省略插件标题和描述区域，搜索栏下方直接展示功能内容
- 配置页提供“插件关键词管理”：可启用或停用插件，查看并修改默认关键词，也可为插件新增关键词；所有设置保存在本机
- 设置页采用左侧分类导航、右侧配置内容的双栏结构；“快捷键管理”统一包含主快捷键与关键词快捷键
- 设置页新增“AI 管理”：可新增、删除、启停供应商，配置 Base URL、OpenAI/Anthropic API 格式、模型列表和上下文窗口；API Key 仅保存在 macOS 钥匙串
- 设置页新增“翻译设置”：可在 Apple 系统翻译与 AI 模型翻译之间切换，并指定已启用的供应商和模型
- 设置页新增“剪贴板设置”，统一管理历史保存时长；收藏记录仍不受自动清理期限限制
- 插件关键词管理中的每个插件使用独立圆角卡片、边框间距和状态色条，启停及关键词区域清晰分隔
- 搜索结果同时覆盖 macOS 本机 App；启动后只在后台低优先级扫描标准 Applications 目录一次，选中后按 `Enter` 直接打开
- 搜索首页以无滚动单列展示最近使用过的 9 个插件和 macOS App，面板随条目数量自动适配高度，并自动去重置顶、保存在本机
- 剪贴板图片的展开栏与列表分割线等宽并使用半透明材质；缩略图右上角始终可直接交给 macOS Preview 查看
- 股票设置可在腾讯财经、东方财富和新浪财经之间切换数据源，并可选择绿涨红跌或红涨绿跌；股票插件支持按保存顺序一键刷新全部查询记录
- 股票列表整行均可一次点击切换；全部刷新按钮紧邻添加按钮，便于快速操作
- 本地剪贴板历史：文本、图片、文件、链接分类过滤，分钟级时间与收藏
- 剪贴板条目支持双击后回到唤起 Luma 前的 App 并直接粘贴；打开、收藏、复制、删除和图片 Preview 按钮统一使用 28 点圆角方形底座
- 双击粘贴会等待目标 App 恢复前台后发送全局 `⌘V`；未授权时会保留复制结果并明确引导开启 macOS 辅助功能权限
- 主面板和设置内容保持扁平视觉，以留白和分割线组织层级；全局按钮、输入框、下拉选项、单选项与开关统一使用轻量圆角底座
- 剪贴板默认保存最近 3 个月，可切换为 3 天、7 天、1 个月、3 个月、6 个月或 1 年；收藏项保留到手动取消收藏或删除
- 安全数学表达式解析器：四则运算、括号、幂与常用函数
- JSON 语法高亮编辑、格式化、压缩和校验
- 系统安全随机数密码生成器，横向滑块设置 6–32 位长度
- 翻译插件支持 Apple 系统翻译（macOS 14.4+）以及自定义 AI 模型翻译；翻译控制区位于输入与结果之间并靠右排列，结果编辑栏始终显示
- Base64、URL 编解码和 SHA-256
- 股票按代码查询：支持 `600115.SS`、`002594.SZ`、`0700.HK`、`AAPL` 等 A 股、港股和美股代码
- 股票查询记录和最近行情保存在本机 `UserDefaults`，最多 20 个标的；仅新增和手动刷新时请求当前选择的公网延迟行情源
- 菜单栏常驻；关闭普通 Dock 图标，降低打扰

## 构建与运行

```bash
cd /path/to/Luma
chmod +x scripts/build-app.sh
./scripts/build-app.sh
```

单独构建会生成不被 LaunchServices 注册的 `dist/Luma.build`；请使用下方安装脚本运行应用。

构建、完整替换 `/Applications/Luma.app` 并自动重启：

```bash
chmod +x scripts/install-app.sh
./scripts/install-app.sh
```

日常开发推荐使用安装脚本，确保运行路径和辅助功能授权目标始终是
`/Applications/Luma.app`。安装过程会先在 `/Applications` 中生成并验证暂存副本，
替换失败时恢复上一版本。

核心工具测试：

```bash
chmod +x scripts/test-core.sh
./scripts/test-core.sh
```

脚本会用系统 Swift 编译器生成并临时签名 `dist/Luma.build`，不下载任何依赖。当前构建目标为 Apple Silicon 和 macOS 14.4+。在完整 Xcode 中也可以直接打开 `Package.swift` 运行。

## 设计取舍

- 插件是编译期原生模块，不加载第三方网页，启动快且边界清楚。
- 剪贴板每 0.8 秒检查一次 `changeCount`，Timer 带 0.25 秒 tolerance；历史保存在 `~/Library/Application Support/Luma/Clipboard`。
- 图片使用独立文件保存，历史索引使用原子 JSON 写入；启动时只加载图片文件引用，避免把数月图片一次性读入内存。
- 过期记录启动时和运行期间自动清理；收藏项不受保存时长限制。剪贴板目录已标记为不参与系统备份。
- Apple 翻译复用系统 Translation；选择 AI 翻译时才按次调用用户配置的公网接口，不引入常驻网络 SDK。
- 股票不下载全市场代码表、不后台轮询；每次只请求用户明确输入的一个代码。公网行情可能延迟，仅供信息展示，不构成投资建议。
